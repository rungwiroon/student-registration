## Changes from v1

### Removed Fields
- ❌ ชั้น/ห้อง (Class/Room) — not needed, single class use
- ❌ เบอร์โทรศัพท์ (Phone) — LINE communication only

### Added Fields
- ✅ เลขที่ (Student Number) — e.g., "12"

### New Sections
- ✅ **รูปแบบเสื้อ** — Image placeholders for Design A and Design B
- ✅ **ตารางขนาดเสื้อ** — Size chart table with chest circumference and length

## Data Structure (Google Sheet Row) — Updated

| A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|
| Date | LINE Name | Student Name | Student No | Order Summary | Total | Slip URL | Status |
| 2024-01-15 09:30 | คุณแม่สมชาย | สมชาย ใจดี | 12 | แบบ A (M=1, L=2) | 750 | /slips/abc.jpg | Pending |

## Static Assets Needed

| Asset | Suggested Path | Note |
|-------|----------------|------|
| Shirt Design A | `/images/shirt-a.jpg` | User to replace with real image |
| Shirt Design B | `/images/shirt-b.jpg` | User to replace with real image |
| Size Chart | Can be inline HTML table | No image needed |

## Anti-Pattern Guards
- Do NOT hardcode image URLs — use relative paths or config
- Size chart is inline HTML (not an image) for accessibility and zoom
- Shirt images are `img` tags with `alt` text and lazy loading
